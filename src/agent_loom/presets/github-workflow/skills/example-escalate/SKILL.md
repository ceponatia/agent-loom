# Escalate without losing work

Classify the blocker first: unclear requirement, missing evidence, environment/access, or reasoning failure. Resolve an information/tool gap without a premium-model reflex. High-risk contracts can go directly to advanced work before failure.

After two ineffective repair hypotheses on the same finding, stop the current worker. Wait for cancellation acknowledgement and subprocess/worktree quiescence. Capture its base/head, owned paths, patch/commits, tests/logs, failed approaches, and precise unresolved question before transferring the write lease.

Give the advanced worker one bounded intervention by default. Preserve useful work and the original finding identity. A replacement agent, new head, or slightly reworded issue does not reset retry limits. Do not restart at the beginning with only the original user prompt.

If advanced work remains blocked, report a focused owner decision or capability gap. The optional deep-rescue role requires explicit authorization and budget; it is not the next automatic retry. Review any resulting patch independently.
