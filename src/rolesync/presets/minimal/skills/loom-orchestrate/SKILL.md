# Coordinate a task

Establish the outcome, acceptance, repository state, and authority. Delegate only when it reduces risk or context load. Keep writers from racing on the same paths. Require exact handoffs: revision, changes, checks, findings, and next action. A green test suite is evidence, not proof that requirements were met.
